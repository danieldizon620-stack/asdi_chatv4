ASDI_Ticketing v5.4 — Dashboard after login

The Server Settings screen opens first. After Save & Connect, the app loads index.php, allowing the existing ASDI login flow to continue to the dashboard. It no longer forces chatroom.php. The Application menu offers Open Dashboard. Existing taskbar badge and notification sound polling are retained.

Build with GitHub Actions or npm install && npm run dist. This package is source code, not a compiled installer. Test the login redirect against your actual server.
